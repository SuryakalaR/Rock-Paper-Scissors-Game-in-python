# ✊ Rock Paper Scissors Game

A simple command-line **Rock Paper Scissors** game developed in **Python**. Play against the computer, check your score, and enjoy multiple rounds until you decide to quit.

---

## 🌟 Features

- Play against a computer with random choices.
- Keeps track of both player and computer scores.
- Displays the result after every round.
- Allows you to play multiple rounds.
- Validates user input to prevent invalid choices.
- Lightweight and easy to run.

---

## 🛠 Technologies Used

- **Programming Language:** Python 3
- **Library:** Built-in `random` module

---

## 📋 Requirements

- Python 3.x installed on your system.
- No external libraries are required.

---

## ▶️ How to Run

1. Save the program as `rps_game.py`.
2. Open a terminal or command prompt.
3. Navigate to the folder containing the file.
4. Run the program using:

```bash
python rps_game.py
```

---

## 🎮 How to Play

1. Enter one of the following choices:
   - `rock`
   - `paper`
   - `scissors`

2. The computer will randomly select its choice.

3. The game displays:
   - Your choice
   - Computer's choice
   - Winner of the round
   - Current score

**Example**

```text
Choose rock, paper, or scissors: rock
You: rock
Computer: scissors

You win!

Score
You: 1
Computer: 0
```

4. After each round, you'll be asked:

```text
Play again? (y/n):
```

- Enter **y** to continue.
- Enter **n** (or any other key) to exit.

When you quit, the program displays:

```text
Bye! Thanks for playing.
```
